# 🧠 Sentiment Analysis using RoBERTa

## 📌 Overview

This project uses a transformer-based NLP model (RoBERTa) to perform sentiment analysis on customer reviews.

---

## 🎯 Objective

Automatically classify customer reviews as positive or negative.

---

## 🧠 Model

RoBERTa (Transformer NLP Model)

---

## 📊 Dataset

Customer reviews with sentiment labels.

---

## ⚙️ Technologies

* Python
* Transformers
* PyTorch
* Pandas

---

## 🚀 How to Run

pip install -r requirements.txt
python main.py

* Sentiment predictions
* NLP-based text classification
